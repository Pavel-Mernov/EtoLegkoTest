# Замер скорости скачивания

Нужен Node.js 22.18.0 или новее с поддержкой запуска TypeScript. Устанавливать зависимости не нужно.

```sh
node speed-test.mts "https://example.com/"
```

Подставьте прямой HTTP(S)-адрес крупного файла, например изображения. Скрипт выполняет 10 последовательных GET-запросов и полностью читает тело каждого ответа перед следующим запросом. Перенаправления обрабатываются автоматически.

В консоль выводятся среднее время запроса в миллисекундах, суммарный объём в байтах и скорость в Мбит/с. Скорость рассчитывается как суммарный объём в битах, делённый на суммарное время запросов в секундах и на 1 000 000. Время отсчитывается от начала запроса до конца чтения тела. Объём учитывает байты тела без HTTP-заголовков. Скрипт запрашивает передачу без сжатия. Если сервер всё же сжимает ответ, учитывается размер тела после распаковки.

При ошибке HTTP, обрыве загрузки или превышении лимита в 120 секунд на запрос скрипт печатает ошибку и завершает работу с кодом 1.
